# Species

Real species live here, one folder per species: `plants/<id>/` (and later `animals/<id>/`),
with `sheets/<n>.json`, `looks/<n>/` and `references/` (spec §10). None yet: the first one is
the algarrobo blanco, `plants/neltuma-alba/`, in phase 2.

The made-up species used to try the viewer and the checks is in `examples/species/`.
